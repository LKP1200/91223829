Central command hub

LuckySearch

Find and run panels, effects, transitions, presets and editing actions from a single keyboard-first window.

Best forReplacing menu hunting with one fast, searchable workflow.

Quick start

About 20 seconds
Assign a shortcut

Open Settings, go to Shortcuts and find LuckySearch under Panels.

Type what you need

Search any part of a panel, effect, preset or action name.

Run it

Use the arrow keys and Enter, or click the result directly.

Collapsible categories

Results stay grouped. Open or close a category once and LuckySearch remembers its state.

Favorites

Click the star beside a result. “See all favorites” turns the result list into a personal toolkit.

Recent actions

With an empty search, up to twelve favorite and recent actions appear as fast buttons.

Quick Paste

The Paste icon sends clipboard content to the timeline and closes LuckySearch.

What can LuckySearch find?

LuckySearch covers LuckyTools panels, LuckyNotes tasks, Project, Sequence, Clip and Item actions, visual and sound effects, visual and sound transitions, visual and sound presets, LuckyAnchor positions, LuckyZoom controls and saved zoom favorites, and LuckyCurves actions.

Some results open a focused second menu. Add Task lets you create and classify a task; Label lets you choose a clip color; Toggle Enable/Disable asks how the alternation should begin; LuckyAnchor lets you choose a target position; transitions can request a duration.

Press Up/Down to navigate, Enter to run and Escape to leave a submenu or close LuckySearch.

Favorites, categories and good habits

  • Click an empty star to save an item; click the filled star to remove it.
  • New installations may start with categories collapsed. Click a heading to expand it.
  • Select the target clip before opening LuckySearch when an action works on clips.
  • Use short, specific search terms and favorite the tools you repeat in every project.
  • The Settings icon opens LuckyTools Settings for shortcuts and appearance.

Configure LuckyShortcuts, control LuckySearch appearance and manage the activation used by this computer.

Find the action

Choose a key

Save

Resolve any conflict, then click OK. Test it with the correct clip selected.

Shortcut categories

  • Panels: LuckySearch and every installed LuckyTools panel.
  • LuckyNotes: add a task without opening the panel first.
  • Project: LuckyOrganize, Save Project and Map Effects Search.
  • Sequence: markers, Save Sequence, Lucky Focus, Unnest, loops, Ladder, Paste and disabled-clip selection.
  • Clip: LuckyBeat, Transfer Keyframes, MaskTrack, Label and Enable/Disable.
  • Item: Adjustment Layer and Solid.
  • LuckyZoom: Analyze, transition, Dynamic Zoom, Eagle View, Align, Reverse, LuckyCurves link and saved zoom presets.
  • LuckyCurves: curve cleaning and inversion actions.
  • LuckyAnchor Motion / Transform: direct shortcuts for every grid position.
  • Effects, transitions and presets: separate visual and sound categories.

The Active filter shows assigned shortcuts only. Clear Category removes the current category; Clear All removes every LuckyTools shortcut. Import and Export move panel shortcuts, action shortcuts and transition durations between computers.

Useful editing actions explained

  • Add Marker to Clip / Selection / Sequence / In-Out: places a marker in the chosen context.
  • Save Project / Save Sequence: saves a version and continues work in a new version.
  • Lucky Focus Lock / Mute: isolates tracks containing the selected clips by locking or muting the rest.
  • Unnest: extracts one nested sequence at a time.
  • Loop Footage: repeats a still or GIF. Loop Keyframes repeats animation as a cycle or ping-pong.
  • Ladder: spaces overlapping clips by a defined distance.
  • Select All Disabled Clips: selects disabled clips in the sequence.
  • LuckyBeat: detects beats in the selected audio and creates rhythmic cuts.
  • Transfer Keyframes: recreates Motion keyframes inside a Transform effect.
  • Paste Keyframes MaskTrack: pastes tracked-mask keyframes using enabled Position, Scale and Rotation properties.
  • Adjustment Layer: reuses the same layer until sequence size changes. Solid creates a unique, recolorable solid.

LuckySearch personalization

  • Background Color: changes the search surface.
  • Title Font: changes the idle title. Search Text Font affects input, results, categories and tags.
  • Button Color Intensity: brightens or darkens quick-action buttons.
  • Safe Layer Insertion: avoids shifting clips upward when adding adjustment layers or solids. Keep it enabled on complex timelines.
  • Native Preset Engine (Experimental): applies presets through Premiere's native interface and requires Map Effects Search calibration.
  • Reset Defaults: returns LuckySearch appearance and options to their defaults.

When using the Native Preset Engine, keep Premiere's Effects panel visible, run Map Effects Search, and recalibrate after major workspace or monitor changes.

License and moving to another computer

  1. Open Settings → License and choose Open My Orders.
  2. Sign in with the email used for the purchase.
  3. Select LuckyTools for Premiere Pro and open the key in Licenses.
  4. In License Details, deactivate the current computer.
  5. Activate the same key on the new computer.

Show reveals the current key when available. Treat the key as private information.

Manual, Automatic and profiles

Manual organizes only when you press LuckyOrganize or its shortcut. Automatic organizes when files enter the project and when Premiere opens. Manual is safer while a profile is being designed.

The profile selector changes the active structure. Use + to create, the pencil to rename and the trash button to remove a custom profile. Save stores the setup; LuckyOrganize stores it and immediately processes the active project.

Create separate profiles for recurring productions—Podcast, Wedding, Commercial, Reels or Corporate—rather than constantly rewriting one setup.

Folders, extensions and Text Filters

Press Add to create a folder, type its name directly on the card, then click the folder icon to enter it and add subfolders. Breadcrumbs and the back arrow move up the structure.

In extensions…, enter a file extension without the dot, such as mov, mp4, wav, mp3, png, jpg, psd or mogrt. In Text Filter…, enter text that must appear in an item's name.

  • AUDIO: wav, mp3, aac.
  • LOGOS: png plus the text filter “logo”.
  • CAM A: mov plus “CAM_A”.
  • B-ROLL: mp4 plus “BROLL”.

A generic extension normally belongs to one folder. It can be shared when text filters make each destination unambiguous. LuckyOrganize warns when a rule conflicts and can move the extension to the new folder.

Audio types and label colors

Right-click a folder and choose Short (SFX) for sound effects or Long (Music) for longer music files. Remove Audio Type clears the classification. This separates files that share wav or mp3 extensions.

The same context menu assigns a folder label color. Right-click individual extension or text-filter pills to assign more specific colors. Remove Label clears the rule.

LuckyOrganize only manages items inside Premiere's Project panel. It does not move, rename or delete the source files on the hard drive.

Grow and Transform in practical terms

Grow applies its behavior from the beginning of the clip regardless of playhead position. It works on regular clips and adjustment layers, preserves uniform scale and includes Curve Editor, Impact Grow and Reverse. Choose it for consistent editorial zooms with native easing.

Transform applies from the current playhead. It supports Shutter Angle motion blur, Full Frame and the LuckyCurves link. Hold Shift while drawing or resizing to release the aspect ratio and scale width and height independently.

The mouse wheel changes the preview magnification so the rectangle can be edited precisely. It does not apply the final zoom by itself.

Static, animated and Dynamic Zoom

With With Transition enabled, Duration controls how long the move takes. In Transform, Shutter Angle adds motion blur; 0 disables it. With Transition off, LuckyZoom creates an immediate or static reframing.

Dynamic Zoom creates continuous motion between two custom frames:

  1. Analyze and draw the first frame.
  2. Enable Dynamic Zoom to reveal two colored rectangles.
  3. Move and resize each rectangle to define the two camera states.
  4. Set Duration and use Invert In and Out if the movement runs backward.
  5. Apply and review the complete move.

Use it for general-to-close-up moves, product-to-product pans, simulated camera travel across a photo or an animated pan-and-zoom. When Dynamic Zoom is disabled, LuckyZoom keeps the tighter rectangle as the main framing.

Align, Eagle View and curves

Align offers Center Guides (cyan) and Rule of Thirds. Rectangle edges, sides and center snap magnetically to enabled guides.

Eagle View zooms the workspace out and allows framing beyond the normal sequence boundary—useful for wide moves, zoom-outs and extreme repositioning.

In Grow, Curve Editor controls Ease In and Ease Out from 0–100. Drag graph points or enter values; the swap button exchanges both values. Impact Grow creates a more expressive response than linear motion.

In Transform, Link with LuckyCurves sends the newly created Position, Scale and related keyframes to the currently chosen LuckyCurves shape.

Recent zooms, favorites and profiles

  • Recent stores up to 20 applied zooms. Click one to restore or reapply it.
  • Click the star to name and save a zoom as a favorite.
  • Profiles separate groups such as Interviews, Reels, Product or Tutorials.
  • Saved favorites also appear in LuckySearch and can receive direct shortcuts.
  • Clear History removes recent entries, not favorite profiles.
  • Undo first clears an active visual selection and can then undo the last LuckyZoom application.
  • Full Frame returns to the complete 100% framing in Transform and can respect Duration and transition settings.

Troubleshooting LuckyZoom

  • No preview: select a visual clip, place the playhead inside it and Analyze again.
  • Apply Zoom disabled: draw a valid rectangle.
  • Non-standard resolution warning: nest the clip or use an adjustment layer.
  • Wrong start time: remember Grow starts at the clip beginning; Transform starts at the playhead.
  • Wrong Dynamic Zoom direction: use Invert In and Out.
  • Unexpected deformation: Shift was probably used in Transform.
  • LuckyCurves link has no visible result: open LuckyCurves, choose a curve and confirm that Link is active.
Silence-driven rough cutting

LuckyCut

Choose method

Start with Enable / Disable for a reversible test.

Execute

Run LuckyCut and leave the active sequence unchanged until it finishes.

Threshold, silence duration and padding

Threshold defines silence. A lower value such as -50 dB preserves very quiet sound and detects less silence. A higher value such as -30 dB detects more silence but may remove soft words or breaths. Start near -40 dB and test the actual recording.

Min. Silence Duration sets how long quiet audio must continue before it becomes a cut. Short values create aggressive, frequent cuts. Longer values preserve conversational rhythm.

Padding In preserves time before speech and Padding Out preserves time after speech. Increase them when consonants, breaths or word tails sound clipped; reduce them when too much silence remains.

Delete Silences vs Enable / Disable

Delete Silences cuts quiet areas and ripple-deletes the gaps, shortening the program. Enable / Disable cuts and changes segment state while keeping the overall timeline duration, which makes it easier to recover material.

Use Enable / Disable for a conservative test. When the parameters are proven, use Delete Silences on a duplicated sequence.

Preview at Playhead shows a waveform and detected regions. Test several kinds of moment—not only one pause—before processing the full sequence.

Profiles and troubleshooting

Profiles store settings for different recordings: studio voice, noisy podcast, course, stream or gameplay. Create, rename and delete custom profiles from the profile bar.

  • No silence found: Scan Sequence, select audio tracks and raise Threshold toward -30 dB.
  • Too many words cut: lower Threshold, increase minimum silence duration, or increase both paddings.
  • Preview or execution uses old tracks: scan again after any sequence or media change.

Mic Names and Tag Mics

Example for two speakers and a wide shot:

  • A1 = Ana, A2 = Luis.
  • V1 = Ana, V2 = Luis.
  • V3 = All Mics.

All Mics makes a wide or shared angle available to every participant. A camera may also be assigned to a specific combination of microphones. LuckyPod needs isolated tracks: if all audio tracks contain the same full mix, it has less information for identifying a speaker.

The current method is Enable/Disable. Multicam Switch is marked Coming Soon and is not available in this version.

Frequency, Threshold and Cut Linked Audio

  • Slow (Focus on speaker): longer shots and fewer changes.
  • Medium (Standard): balanced and the best starting point.
  • Fast (Dynamic): frequent changes for energetic or short-form content.

Threshold determines when a mic is active. If voices are missed, raise it toward -30 dB. If room noise or bleed triggers the wrong camera, lower it toward -40 or -45 dB. Start near -35 dB.

With Cut Linked Audio off, LuckyPod prioritizes video switching and protects continuous audio. Turn it on only when the edit should include linked audio cuts.

Profiles and final review

Profiles store mic/POV count, names, mappings, threshold, frequency and Cut Linked Audio. Keep one per studio, show or recurring setup.

Duplicate the sequence before processing. After LuckyPod completes, review interruptions, simultaneous speech, reaction shots, long silent stretches and moments where a wide shot is editorially stronger than the detected speaker angle.

Notes, Auto-Tags and links

Select text before using B, I, U, alignment, Font Color, Highlight Color or the size controls. Notes save automatically.

With Auto-Tags active, compatible timecodes become clickable; selecting one moves the timeline playhead. Recognized web addresses open in the default browser. Right-click a generated tag to remove it or customize supported tag colors.

Auto-Tags can be disabled when you want plain text with no automatic recognition.

Working with reference images

  1. Paste an image from the clipboard or drag an image file into Notes.
  2. Click the image to select it.
  3. Use Left, Center or Right alignment; resize from its container where available.
  4. Use Delete/Backspace or right-click → Delete to remove it.
  5. Right-click → Import to Timeline to bring the image into the project and place it on an available video track.

When a time range is selected, image duration may follow that range; otherwise insertion begins at the playhead.

Tasks and LuckySearch

Type into Add new task and press Add Task or Enter. New tasks begin as Pending. Change the colored status, drag to reorder, and use X to delete.

  • All: every task.
  • Urgent: red.
  • Pending: yellow.
  • Done: green.

Add Task can also run from LuckySearch or a direct shortcut. Tasks and their states stay synchronized between both panels.

Animation dynamics and easing

LuckyCurves

Shape how an animation accelerates and settles, reuse favorite dynamics and create expressive Squash & Stretch motion.

Best forTitles, graphics, position and scale animation, and consistent motion language.
Select the animation

Select the clip and place the playhead between the two keyframes defining the move.

Choose a curve

Select a family, In / In-Out / Out, or a saved preset.

Apply

Click the lightning Apply Curve button and preview the complete movement.

Curve families and when to use them

  • Sine: soft and natural.
  • Quad: clear but moderate acceleration.
  • Cubic: stronger and more cinematic.
  • Quart / Quint: progressively sharper and faster at the extremes.
  • Expo: intense, dramatic change.
  • Circ: rounded and organic.
  • Back: slightly overshoots and returns.

In starts slowly and accelerates. Out starts quickly and settles. In-Out softens both ends and is a reliable choice for position and scale.

Editing, locking, inverting and cleaning

Drag the graph handles or the In and Out readouts. Hold Alt for fine adjustment. Hold Shift to unlock normal curve limits and create more extreme shapes.

  • Lock: prevents accidental curve editing.
  • Invert Curve: reverses the visual curve shape.
  • Invert Keyframes: reverses selected keyframe direction/order.
  • Clean Curve: removes the applied curve or returns the animation to a clean state.

If “Playhead out of range” appears, place the playhead between two keyframes and apply again.

Squash & Stretch, presets and LuckyZoom

Toggle Deform Mode enables Squash & Stretch, coordinating properties such as Position, Scale and Rotation for expressive motion. It is particularly effective on titles, icons and stickers; use it carefully on live-action footage.

Save Curve stores the current shape. New Profile creates a preset bank, and Delete this profile removes a custom bank. Build groups such as Soft, Impact, Reels, Titles, Lower Thirds and Zooms.

When linked from LuckyZoom Transform, the active curve can be applied to the zoom's newly created Position, Scale and related keyframes.

Mathematical anchor placement

LuckyAnchor

Place the anchor at one of 25 precise positions for Motion or Transform while compensating the image position so the clip does not visually jump.

Best forSetting the correct origin before scale and rotation animation.
Select a visual clip

Video, still, graphic or shape can be used.

Choose the system

Use Motion by default, or toggle Transform when a compatible effect exists.

Click a grid point

The anchor updates immediately and the active position stays highlighted.

The 25-point grid

The grid includes corners, side centers, the exact center and intermediate Mid positions. Top Left makes scale and rotation originate at the upper-left corner; Top Center uses the upper edge; Center uses the precise middle; Middle Left and Middle Right use the side centers; Bottom points use the lower edge.

Intermediate points offer finer origins without manually calculating coordinates. The visual position is compensated when the anchor moves.

Motion, Transform, shortcuts and timing

LuckyAnchor targets Motion by default. When the selected clip contains a compatible Transform effect, the Transform toggle becomes available. Use the same system as the animation you intend to control.

You do not need to keep the panel open. Settings provides separate LuckyAnchor Motion and LuckyAnchor Transform categories, with a direct shortcut for every grid point. The same positions are searchable in LuckySearch.

Set the anchor before building scale or rotation keyframes whenever possible. If you change it after a complex animation already exists, review the result carefully.

Before large operations

Safety checklist

  • Save the project and duplicate the sequence before LuckyCut or LuckyPod.
  • Confirm the active sequence, playhead and selection before using a shortcut.
  • Do not switch sequences while an analysis or large edit is running.
  • Test audio thresholds on a short representative range first.
  • Use profiles so a proven setup is not overwritten.
  • Export shortcuts after completing an important keyboard layout.
  • Remember that LuckyTools accelerates the first pass; the final editorial judgment remains with the editor.
