01

LuckySearch

Find and run what you need without leaving your flow.

ModesSearch · favorites · quick actions
What it does

Brings panels, effects, transitions, presets and editing commands into one keyboard-first window.

Best for

Replacing menu hunting with one fast, searchable workflow.

How LuckySearch works
Everything in one search

Find LuckyTools panels, Project, Sequence, Clip and Item actions, effects, transitions, presets, LuckyNotes tasks, LuckyZoom controls, LuckyAnchor positions and LuckyCurves actions.

Categories that remember

Results stay grouped in collapsible categories. Open or close a category once and LuckySearch remembers its state for the next search.

Favorites and recent actions

Star the tools you repeat. With an empty search, up to ten favorite and recent actions become persistent one-click buttons.

Clear, complete names

Recent and favorite effects display their full names without abbreviations. Search in Spanish even when Premiere Pro is configured in English.

Fast keyboard-first control

Locally indexed results update as you type. Use Up and Down to navigate, Enter to run a result and Escape to leave a submenu or close the search window.

Curve preview and Quick Paste

Preview supported motion curves before applying them, or send clipboard content directly to the timeline with Quick Paste.

Adobe API note: custom interpolation curves may not be preserved when a preset is applied programmatically, so manual easing adjustments can occasionally be required.

02

LuckyShortcuts

Turn repetitive actions into direct buttons and shortcuts.

ModeOne action per shortcut
What it does

Maps panels, tools, effects, transitions, presets and editing actions directly to keys or buttons.

Best for

Eliminating repeated clicks and building a dependable personal workspace.

How LuckyShortcuts works
Direct 1-to-1 mapping

Assign one Premiere Pro or LuckyTools action to each shortcut. The panel intentionally does not run multi-step macros.

Complete action library

Map panels, markers, project and sequence tools, clip actions, adjustment layers, solids, effects, transitions, presets, LuckyZoom, LuckyCurves and all 25 LuckyAnchor positions.

Conflict-aware setup

Search for an action, choose a key or key combination and resolve conflicts before saving. The Active filter shows assigned shortcuts only.

Portable configuration

Import and export panel shortcuts, action shortcuts and saved transition durations when moving to another computer.

Designed for stability: LuckyShortcuts executes one command per keypress. It is not a macro recorder.

03

LuckyOrganize

Start every project with everything in its place.

ModesManual · automatic
What it does

Creates nested bins and sorts project items using extension, filename, audio-type and color rules.

Best for

Repeatable templates for podcasts, weddings, ads and social content.

How LuckyOrganize works
Reusable profiles

Create a different organization profile for each recurring production. Test a new profile in Manual mode, then switch to Automatic when every rule behaves correctly.

Nested project structure

Build bins and sub-bins, move through them with breadcrumbs and save the complete structure for the next project.

Precise sorting rules

Combine extensions such as mov, wav, png or mogrt with filename text filters, Short SFX or Long Music classifications and Premiere label colors.

Safe project management

LuckyOrganize changes only the organization inside Premiere Pro's Project panel. It does not move, rename, import or delete source files on your drive.

04

LuckyZoom

Create precise punch-ins without fighting scale and position.

ModesGrow · Transform · Dynamic
What it does

Analyzes the frame and turns a visual selection into a static reframe, animated punch-in or two-point camera move.

Best for

Tutorials, gameplay, vertical videos and any edit that needs to guide the viewer's eye.

How LuckyZoom works
Analyze, draw and apply

Select a clip, analyze the frame and draw the composition you want. Move or resize the selection, choose the behavior and apply the result.

Grow mode

Creates consistent editorial zooms from the beginning of the clip with uniform scale, a built-in curve editor, Impact Grow and Reverse.

Transform mode

Starts from the current playhead, supports Shutter Angle motion blur and can link new Position and Scale keyframes to LuckyCurves.

Dynamic Zoom

Define independent A and B frames for zoom-ins, zoom-outs, lateral reframing and simulated camera travel. Control duration and invert the movement when needed.

Free Aspect and Eagle View

Hold Shift in Transform to stretch, squash or skew the frame independently. Eagle View lets you compose beyond the normal sequence boundary.

Guides, history and favorites

Snap to center or rule-of-thirds guides, navigate with the mouse wheel, restore recent zooms and save named favorites in separate profiles.

05

LuckyCut

Reach a clean first cut sooner.

ModeSilence detection
What it does

Analyzes audio, previews cuts and lets you adjust the threshold, minimum duration and margins before changing the sequence.

Best for

Talking heads, interviews, courses and long recordings with pauses.

How LuckyCut works
Fast local analysis

Scan the active sequence, choose the video and audio tracks to process and detect quiet sections through audio levels without cloud processing.

Editable detection

Threshold defines what counts as silence, Minimum Silence Duration controls how long it must last, and Padding In and Out preserve the edges of spoken words.

Preview before processing

Preview the waveform and detected regions at the playhead. Test loud, quiet and soft-spoken moments before running the full sequence.

Two processing methods

Delete Silences shortens the edit with ripple deletion. Enable / Disable keeps the timeline duration and provides a more reversible first pass.

Recommended workflow: duplicate the sequence first and save profiles for different recording environments.

06

LuckyPod

Keep a multicamera conversation moving automatically.

ModeMulticamera auto-switch
What it does

Maps isolated microphones to camera angles, detects who is speaking and builds a first multicamera pass.

Best for

Podcasts, interviews and conversations with two or more participants.

How LuckyPod works
Microphone-to-camera mapping

Use one isolated audio track per speaker and map each microphone to its matching camera, a combination of cameras or an All Mics wide shot.

Flexible productions

Configure between one and ten microphones and camera angles, name each speaker and save the complete setup as a reusable profile.

Editorial behavior

Choose Slow, Medium or Fast switching, tune the dB threshold and decide whether linked audio should remain protected or be cut.

Private local processing

Audio analysis runs on your computer with no AI service and no uploaded media. The current method creates the pass with Enable / Disable.

Current version: Multicam Switch is still marked Coming Soon. Review overlaps, reaction shots and wide-angle choices after the automatic pass.

07

LuckyNotes

Keep every task beside the edit.

ModesNotes · tasks · references
What it does

Keeps formatted notes, clickable timecodes, reference images and status-based tasks beside the edit.

Best for

Feedback rounds, long deliveries and edits that continue across multiple days.

How LuckyNotes works
Rich notes

Format text with bold, italic, underline, alignment, text color, highlight color and multiple sizes. Notes save automatically.

Clickable timecodes and links

Auto-Tags converts supported timecodes into playhead navigation and recognized web addresses into links without adding timeline markers.

Visual references

Paste or drag images, align and resize them, or import a selected reference into the Premiere project and timeline.

Synced task system

Create, reorder and filter Urgent, Pending and Done tasks. Add Task also works from LuckySearch or a direct shortcut.

08

LuckyCurves

Shape easing, dynamics and expressive Squash & Stretch motion.

ModesVelocity · value · deform
What it does

Shapes acceleration, spatial values and deformation with visual curves, reusable profiles and direct keyframe controls.

Best for

Text, graphics, scaling and motion that need a natural entrance or exit.

How LuckyCurves works
Velocity and Value graphs

Control how quickly animation accelerates and settles, or shape spatial interpolation beyond its normal range for more organic movement.

Complete curve library

Choose Sine, Quad, Cubic, Quart, Quint, Expo, Circ or Back, then select In, Out or In-Out. Elastic, Bounce and Step families add more stylized timing.

Squash & Stretch

Deform mode coordinates Position, Scale and Rotation to inject weight, inertia and expressive physics into titles, icons, stickers and graphics.

Hands-on editing

Drag graph handles or numeric In and Out values. Hold Alt for fine adjustment and Shift to unlock the normal curve limits.

Reusable motion language

Save curves in named profiles for titles, lower thirds, zooms or impact moves, then reuse the same motion behavior across projects.

Direction and cleanup

Reverse keyframes, invert the graph or clean an applied curve. LuckyZoom Transform can send newly created keyframes directly to the selected curve.

09

LuckyAnchor

The right anchor point, exactly where you need it.

Mode25-point positioning
What it does

Moves the anchor with mathematical precision while compensating Position so the image does not visually jump.

Best for

Setting the correct origin before scale and rotation animation.

How LuckyAnchor works
25-point precision grid

Choose corners, edge centers, the exact center and intermediate positions for finer placement without calculating coordinates by hand.

Motion and Transform

Target Premiere Pro's native Motion controls by default or switch to a compatible Transform effect when that is the system driving the animation.

No visual jump

LuckyAnchor compensates Position as Anchor Point changes, keeping the element visually in place while changing the origin of scale and rotation.

Shortcuts and search

Every Motion and Transform grid position can receive a direct shortcut and can also be launched from LuckySearch.

Custom pixel offsets

Fine-tune the chosen position with exact coordinate offsets for specialized layouts and pixel-perfect framing.

Best practice: set the anchor before creating scale or rotation keyframes. If complex animation already exists, review the result after moving it.

Which Premiere Pro languages are supported?

LuckySuite works exclusively with Adobe Premiere Pro configured in English or Spanish. Other languages are not supported yet.

Does it work on macOS?

No. LuckySuite is currently available for Windows only. If you use a Mac, do not purchase the plugin because it will not run on your system.

Which version of Premiere Pro do I need?

Stable compatibility is guaranteed for Premiere Pro 2026 (v26.0) or later. It may open in earlier versions, but errors or instability can occur.

How does the license work?

Each purchase includes one license per computer. You can deactivate it from your LemonSqueezy account and activate it again if you change computers or reinstall Windows.

Are updates included?

Your purchase includes 1 full year of updates, keeping your tools fresh at the start of every new year. Could there be bugs or limitations?

LuckySuite continues to grow. Minor issues may appear in specific scenarios; community feedback is used to publish fixes and improve stability.
