Version 1.0.5 Latest Stable

A faster LuckyPod with real-time preview, the new CopyCuts tool, clearer LuckyCut and LuckySearch workflows, and more reliable licensing.

Latest stable: 1.0.5 Windows Premiere Pro 2026+
Not sure how to update? Go to Contact or join the Discord server for help.

Version 1.0.5

Latest stable

A major LuckyPod rebuild with faster cutting and real-time preview, the new CopyCuts workflow, clearer tools, and stronger license stability.

LuckyPod

  • LuckyPod has been restructured around an improved cutting engine for significantly faster processing.
  • The workflow order has been updated, with Preview now presented as the second option.
  • Configuration labels and loading messages now use clearer, easier-to-understand language.
  • New real-time preview shows a simulation of the resulting cuts before anything is applied.
  • You can now preview the multicamera result before committing the edit.

CopyCuts

  • Added CopyCuts, a new tool for copying the cuts from one clip to other selected clips.
  • The clip with the greatest number of cuts is automatically used as the source.
  • Select the destination clips and CopyCuts completes the transfer automatically.

LuckyCut

  • Reordered the tools to make the workflow easier to follow.
  • Simplified labels and terminology for quicker understanding.
  • Updated the loading screen for clearer progress feedback.

LuckySearch

  • Removed search-bar customization in favor of greater speed and stability.
  • Recent and favorite effects now display their full names without abbreviations to prevent confusion.
  • The recent and favorite item limit has been adjusted from 12 to 10.

Licenses

  • Improved license-system stability to address cases where an active license could be revoked unexpectedly.

Version 1.0.4

Previous stable

A focused motion workflow update with corrected animated anchor compensation, visual clip reordering, a dedicated Labels panel, improved preset stability, and Premiere Pro 26.2.3 compatibility.

LuckyAnchor

  • Fixed anchor-point changes on Squash & Stretch animations so the image remains visually still while the anchor moves.

Reverse Order

  • Reverse Order is now available in the Clip category.
  • Selected clips can exchange their visual order in the preview without moving to different positions on the timeline.
  • The command swaps the clips' Motion properties rather than moving the clips themselves.

Labels Panel

  • Labels, previously available through LuckySearch, now also has its own dedicated panel for quicker access.
  • Labels can be arranged horizontally or vertically for a more comfortable workflow.
  • The dedicated layout makes frequently used labels faster to find and apply.

LuckyZoom

  • Restored reliable Grow behavior in Premiere Pro 26.2.3, including Spanish-language installations.

Presets & Reliability

  • Fixed an issue where presets could be read successfully but stop before being applied to the selected clips.
  • Preset application has been reinforced for greater stability and more dependable results.

Version 1.0.3

Earlier release

A workflow update led by Better Effects, tracking from LuckySearch, configurable Paste storage, dependable transitions, more flexible Ladder modes, and faster timeline tools.
Version 1.0.3Play here
Better Effects

Popular effects now start closer to the result editors actually want.

Apply these effects from LuckySearch or a shortcut and get more useful, intuitive starting values instead of Premiere Pro's generic defaults.

VR Glow Roughen Edges Drop Shadow Wiggle Stroke and more
Signature effect Ultra Key — automatic chroma removal

Analyzes the clip and automatically selects the chroma background color to remove, whether it is green, blue, red, or another color.

Community-informed defaults Feedback collected from Busco Editor creators Collected usage data and editor feedback helped set practical defaults for VR Glow, Roughen Edges, Drop Shadow, Wiggle, Stroke, Transform, and more. Premiere Pro's original controls remain available; Better Effects reduces repetitive setup—for example, Transform starts with a 180° Shutter Angle—so common looks take fewer adjustments.
Tracking

Start tracking directly from LuckySearch.

Tracking can now be launched from the search bar. Under the hood, it uses mask tracking and the generated mask keyframes to follow motion across the clip.

Release Highlights

  • Safer Paste storage: Choose where Paste saves its files. By default, they are now stored beside the active project instead of in the temporary folder, helping prevent missing-file and path errors.
  • Full-name reverse search: Enter the effect's complete name—even with its words reversed—to get the result, such as “VR Glow” or “Glow VR.”
  • Reliable transitions: Better placement, multi-clip support, and no more strange visual resizing after application.

LuckySearch & Effects

  • Search has been optimized for quicker, more responsive results.
  • Reverse word-order search requires the effect's complete name—for example, entering the full names “VR Glow” or “Glow VR” returns the same result.
  • Tracking can now be started directly from LuckySearch; it uses mask tracking and the generated mask keyframes to follow motion.
  • Tracking commands can also be assigned to shortcuts from LuckyTools Settings.
  • The Transform effect no longer displays both scale controls when Uniform Scale is enabled.
  • Roughen Edges now starts with practical values that produce the rounded-edge look commonly used in daily editing.
  • Better Effects applies community-informed defaults to popular visual effects for faster first results.

Transitions

  • When the playhead is positioned inside a clip, transitions are now placed correctly at the beginning and end of that clip.
  • Fixed transition application issues that could cause strange visual resizing.
  • Transitions can now be applied to multiple stacked clips when those clips share the same duration.
  • Ladder no longer damages transitions on stacked clips.

Fixes & Reliability

  • LuckyCurves now clears Squash & Stretch correctly and removes it only from active clips.
  • Fixed overlapping labels in LuckyNotes.

Paste & File Storage

  • Paste now lets you choose the folder where its files are saved.
  • By default, Paste saves files in the active project's location instead of the temporary folder.
  • Keeping pasted files with the project helps prevent missing-file, temporary-path, and relinking errors.

Ladder, Nest & Unnest

  • Reverse mode: preserves the normal staggered starts while reversing the ending order—the top clip finishes first and the bottom clip finishes last.
  • Same End mode: keeps staggered starts using the chosen value while aligning every clip to exactly the same ending point.
  • Nest is now available in the Shortcuts list.
  • Unnest is dramatically faster.

LuckyZoom

  • LuckyZoom now applies framing correctly to high-resolution clips such as 4K footage with both Grow and Transform.
  • LuckyZoom analysis is now more optimized for faster, more efficient results.

LuckyAnchor

  • LuckyAnchor now includes a new Visible Content button.
  • Visible Content reads the pixels that are actually visible and ignores empty or transparent space around them when calculating the anchor point.
  • The anchor is positioned relative to the artwork or subject that can be seen, rather than the clip's full rectangular bounds, providing more accurate placement when the visible content occupies only part of the frame.

Version 1.0.2

Earlier release

A larger workflow update with recommended shortcuts, clearer shortcut availability, deeper LuckySearch integration, redesigned LuckyZoom controls, panel upgrades, performance improvements, interface polish, and bug fixes.

Highlights

  • Recommended shortcut list: LuckyTools now suggests practical shortcuts, shows which ones are available or unavailable, and blocks unsafe combinations like Ctrl+C and Ctrl+V so you do not have to guess what to assign.
  • Deeper LuckySearch integration: More function details, LuckyZoom tools, favorites, and LuckyNotes tasks are now visible and manageable directly from LuckySearch.
  • Workflow improvements: LuckyPod, LuckyCut, and LuckyOrganize have been turned into dedicated panels for faster access.
  • Performance and interface polish: Faster everyday interactions, cleaner controls, and smoother panel behavior across the update.

Shortcuts & LuckySearch

  • Keyboard shortcuts now correctly open LuckySearch for functions like Ladder, Loop Footage, and other quick actions.
  • Added a recommended shortcuts list so users can choose useful defaults without thinking too much about which keys to use.
  • Shortcut assignment now shows available and unavailable shortcuts more clearly.
  • Unsafe or protected shortcuts, including common system actions like Ctrl+C and Ctrl+V, are blocked for safety.
  • Function information that was previously visible only in LuckyTools Settings is now available inside LuckySearch.
  • Added import and export support for keyboard shortcuts.
  • Added controls to clear shortcut categories, clear all shortcuts, and manage license actions.

Fixes & Panels

  • Improved performance across daily panel interactions and shortcut workflows.
  • Polished interface details for cleaner controls and easier scanning.
  • Fixed several minor bugs across everyday workflows.
  • LuckyPod, LuckyCut, and LuckyOrganize are now available as panels.
  • Fixed a LuckyOrganize bug where sequences were not being saved correctly.

LuckyZoom

  • LuckyZoom has been redesigned, including a cleaner position for the Analyze button.
  • LuckyZoom now has deeper integration inside LuckySearch.
  • Saved LuckyZoom favorites can now be viewed from LuckySearch.
  • Many new LuckyZoom panel buttons and functions can now be assigned shortcuts or accessed from LuckySearch.

LuckyNotes

  • LuckyNotes has deeper LuckySearch integration.
  • Tasks can now be viewed from LuckySearch.
  • Tasks can be deleted or moved between priorities from LuckySearch, with real-time updates in the LuckyNotes panel.

Anchor Points & Presets

  • LuckyAnchor now updates anchor points by reading clip data, so opening Effect Controls is no longer required.
  • Fixed a GIF anchor point bug where some GIFs did not move correctly.
  • Presets now apply correctly when saved with Scale and Out points.

Version 1.0.1

Earlier release

More Curves Updated! A bigger motion, audio, search, and framing update for faster everyday editing.

Highlights

  • New animation curves: Elastic, Bounce, and Step curves are now available for creating sharper impacts, reactive movement, stylized timing, and more playful motion.
  • Curve previews for every new mode: Each new curve includes a clear visualizer so you can understand the motion shape before applying it.
  • Beat Detector added: Analyze music and automatically cut audio to the rhythm, making beat-based edits faster and easier to build.

LuckyCurves

  • Added Elastic, Bounce, and Step curve families for more expressive animation timing.
  • Improved accessibility across curve controls and visualizers for clearer navigation and feedback.
  • Added a button to invert the curve graphic preview.
  • Added a new button to invert applied keyframes or any existing animated keyframes directly in Effect Controls.
  • Squash and Stretch curves can now be applied and cleaned more reliably depending on the selected property.
  • Curve cleanup is more precise when switching between supported property types.

LuckyZoom

  • Fixed special cases where LuckyZoom could fail to apply the effect correctly.
  • Added framing guides with optional ruler and grid overlays for more accurate composition.
  • Improved reliability when creating zooms in less common sequence or clip situations.

LuckyBeat

  • Added LuckyBeat, a new beat-based cutting workflow for slicing clips in sync with music rhythm.
  • Added Toggle Enable/Disable, a new function that alternates enabled and disabled clips sequentially across a multi-clip selection.
  • Designed for quick music-driven edits, beat chops, rhythmic pacing, and faster timeline preparation.
  • Helps turn a full track into editable rhythmic segments without manually hunting for every beat.

Speed Improvements

  • The search bar now opens faster and feels more responsive when launching LuckySearch.
  • Preset application is faster when applying the same preset across multiple selected clips.
  • Reduced waiting time in multi-clip workflows so batch edits feel smoother and more predictable.

Fixes

  • Fixed preset application when a preset contains two Transform effects, preserving the correct effect order.
  • Fixed several smaller bugs reported across daily editing workflows.
  • Improved consistency when applying and clearing curve data from selected properties.
  • General stability polish for a cleaner, faster LuckyTools experience.
