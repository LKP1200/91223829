Version 1.0.2

Coming soon

A larger workflow update with deeper LuckySearch integration, redesigned LuckyZoom controls, panel upgrades, shortcut management, and bug fixes.

Highlights

  • Keyboard shortcut import and export: Shortcuts can now be imported, exported, cleared by category, cleared completely, and managed alongside license controls.
  • Deeper LuckySearch integration: More function details, LuckyZoom tools, favorites, and LuckyNotes tasks are now visible and manageable directly from LuckySearch.
  • More panels: LuckyPod, LuckyCut, and LuckyOrganize have been turned into dedicated panels for faster access.

Shortcuts & LuckySearch

  • Keyboard shortcuts now correctly open LuckySearch for functions like Ladder, Loop Footage, and other quick actions.
  • Function information that was previously visible only in LuckyTools Settings is now available inside LuckySearch.
  • Added import and export support for keyboard shortcuts.
  • Added controls to clear shortcut categories, clear all shortcuts, and manage license actions.

LuckyZoom

  • LuckyZoom has been redesigned, including a cleaner position for the Analyze button.
  • LuckyZoom now has deeper integration inside LuckySearch.
  • Saved LuckyZoom favorites can now be viewed from LuckySearch.
  • Many new LuckyZoom panel buttons and functions can now be assigned shortcuts or accessed from LuckySearch.

LuckyNotes

  • LuckyNotes has deeper LuckySearch integration.
  • Tasks can now be viewed from LuckySearch.
  • Tasks can be deleted or moved between priorities from LuckySearch, with real-time updates in the LuckyNotes panel.

Anchor Points & Presets

  • LuckyAnchor now updates anchor points by reading clip data, so opening Effect Controls is no longer required.
  • Fixed a GIF anchor point bug where some GIFs did not move correctly.
  • Presets now apply correctly when saved with In and Out points.

Fixes & Panels

  • Fixed several minor bugs across everyday workflows.
  • LuckyPod, LuckyCut, and LuckyOrganize are now available as panels.
  • Fixed a LuckyOrganize bug where sequences were not being saved correctly.

Version 1.0.1

Latest stable

More Curves Updated! A bigger motion, audio, search, and framing update for faster everyday editing.

Highlights

  • New animation curves: Elastic, Bounce, and Step curves are now available for creating sharper impacts, reactive movement, stylized timing, and more playful motion.
  • Curve previews for every new mode: Each new curve includes a clear visualizer so you can understand the motion shape before applying it.
  • Beat Detector added: Analyze music and automatically cut audio to the rhythm, making beat-based edits faster and easier to build.

LuckyCurves

  • Added Elastic, Bounce, and Step curve families for more expressive animation timing.
  • Improved accessibility across curve controls and visualizers for clearer navigation and feedback.
  • Added a button to invert the curve graphic preview.
  • Added a new button to invert applied keyframes or any existing animated keyframes directly in Effect Controls.
  • Squash and Stretch curves can now be applied and cleaned more reliably depending on the selected property.
  • Curve cleanup is more precise when switching between supported property types.

LuckyBeat

  • Added LuckyBeat, a new beat-based cutting workflow for slicing clips in sync with music rhythm.
  • Added Toggle Enable/Disable, a new function that alternates enabled and disabled clips sequentially across a multi-clip selection.
  • Designed for quick music-driven edits, beat chops, rhythmic pacing, and faster timeline preparation.
  • Helps turn a full track into editable rhythmic segments without manually hunting for every beat.

Speed Improvements

  • The search bar now opens faster and feels more responsive when launching LuckySearch.
  • Preset application is faster when applying the same preset across multiple selected clips.
  • Reduced waiting time in multi-clip workflows so batch edits feel smoother and more predictable.

LuckyZoom

  • Fixed special cases where LuckyZoom could fail to apply the effect correctly.
  • Added framing guides with optional ruler and grid overlays for more accurate composition.
  • Improved reliability when creating zooms in less common sequence or clip situations.

Fixes

  • Fixed preset application when a preset contains two Transform effects, preserving the correct effect order.
  • Fixed several smaller bugs reported across daily editing workflows.
  • Improved consistency when applying and clearing curve data from selected properties.
  • General stability polish for a cleaner, faster LuckyTools experience.
